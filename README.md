# Nokia OS Prototype v0.2

Prototipo web/PWA optimizado para iPhone 13 (viewport lógico 390 × 844 pt).

## Qué incluye
- Navegación con historial real y botón ‹ en todas las apps.
- Gesto desde el borde izquierdo para volver.
- Home, Messages, Compose, teclado T9/ABC, Snake, Contacts, Calls, Music, Camera, Clock y Settings.
- Diseño adaptado a iPhone 13 y safe areas.
- Manifest + Service Worker para instalarlo en la pantalla de inicio como PWA.
- Funciona offline después de la primera carga cuando se sirve por HTTPS.

## Usarlo en iPhone
1. Abre la URL pública en Safari.
2. Pulsa Compartir.
3. Elige **Añadir a pantalla de inicio**.
4. Activa **Abrir como app web** si iOS lo muestra.
5. Pulsa Añadir.

## Nota
Esto es un prototipo web. Para APIs profundas de iOS, cámara vintage real, contactos, mensajería y mejores hápticos, el siguiente paso será portar la experiencia a SwiftUI/Xcode.
